# Patriot Claims Inspection Report — Template Structure

Source: `docs/templates/patriot-inspection-report-template.pdf` (60 pages, real claim example).
Brand: navy `#1b1f4e` bands, red `#d32f2f` accents, Patriot Claims logo, white content area.

## Page 1 — Cover
Navy top band → logo → "INSPECTION REPORT" (navy, bold) → front-of-house photo (portrait,
timestamp burned bottom-left) → CLAIM NUMBER / INSURED / LOSS ADDRESS block →
"PROFESSIONALLY PREPARED BY PATRIOT CLAIMS", date, `<Inspector>, INSPECTOR` → navy footer with
website + phone.

## Page 2 — Inspection Summary
Header band (all content pages): left "Inspection Report" + service date + claim # + insured;
center logo; right corporate office address/phone/email. Footer band: claim #, inspection type,
page number in white circle `~ N ~`.

Body: INSPECTION SUMMARY table (navy header cells):
claim number | inspection date | inspection type | date of loss
insured | loss address | structure type | stories
carrier | adjuster | inspector | inspector contact
OTHER STRUCTURES row.
Then rounded text boxes: **INSPECTOR SUMMARY**, **LOWER ELEVATIONS**, **ROOF** (free-text
narratives).

## Page 3 — Roof Assessment Form (dense, single page)
- Header strip: claim number/insured/loss address | inspector name/OA name/job type
- CHECK ALL WHO WERE ON THE ROOF: Patriot Rep / Outside Adjuster / Contractor / Other
- AERIAL MEASUREMENTS yes/no; FRONT OF HOUSE DIRECTION (compass)
- ROOF TYPE box: material + age, predom pitch, stories, layers, layer type
- RIDGE / VALLEY / HIP materials
- COLLATERAL: DAMAGE AND TOTAL COUNT list (box vents, turbines, HVAC vents, power vents, pipe
  jacks, chimney cap, skylights, rain diverters, ridge vent, satellite/ant, exhaust vents,
  ice/water shield, drip edge, gutters) as `n of m`
- ROOF CONDITIONS matrix — rows: blisters, cup curl, deck rot, granule loss, manufacturer
  defects, mechanical, nail pops, prior repairs, thermal cracking × columns F L B R (checks)
- TEST SQUARE COUNT table per slope F/L/B/R: total slope count, size, potential hail count,
  potential wind count
- TARP R/R table per slope: D&R tarps, new tarps, detach tarps
- CAD SKETCH (aerial image w/ markup) + CAD SKETCH KEY legend (TS, SAT, RV, ANT, X, EV, PV, RD,
  ORV, TV, BV, TD, PJ, HVAC, CC, SKY, SP)
- GUTTER and DOWNSPOUT tables per elevation: n of m, size, paint, material
- ROOF COMPONENTS text block: eave depth, drip edge details, underlayment

## Page 4 — Roof Components (continued)
Text outline: main material/shingle gauge, pitch, ridge, hips, valley; then per-facet blocks
(slope findings, tarp details) and per-direction blocks (test square size + hail count + other
findings; vents with `n of m`, sizes, materials, painted).

## Page 5 — General Inspection Questions
Two-column table: question | Yes/No. (Named insured home? Get on roof? Potential hail or wind
damage? Collateral consistent with report?)

## Page 6+ — Main Dwelling Interior Findings Sheet (one table per room)
Room name, perimeter length, baseboards, ttl ceiling sqft, ttl wall sqft, crown molding,
ceiling height, affected ceiling sqft, ceiling fans, affected wall sqft, total wall sqft,
vent/light counts, wall texture, window/smoke detector, ceiling texture, room notes, other.

## Photo Sheets (bulk of report)
"INSPECTION PHOTO SHEET" heading; **two portrait photos per page**, left-aligned; timestamp
`MM/DD/YYYY HH:MM:SS` burned bottom-left of each photo; **bold label** to the right of each
photo (e.g. `Front of House`, `Dining Room overview(8x12)` with sub-line `Room name: Dining
Room`, `Front Slope Test Square q4 overview`, `Front Slope Test Square q4 potential granule
loss`). Photos appear in capture-flow order: branding → vehicle → front of house → risk
address → interior rooms → elevations → eave items → roof components → test squares → wind.

## Final Page — Subrogation Opportunities + Closing
Subrogation table (improper nail/staple size, nail/staple not on line, improper fasteners,
improper shingle exposure, manufacturer defects | Yes/No). Then centered closing block:
"This Inspection Report has been proudly prepared by Patriot Claims." + corporate office
address, phone band, email, website line, red "Request Inspection" button.
